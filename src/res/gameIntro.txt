🐍 贪吃蛇大作战 · 介绍 & 教程

══════════════════════════════════════════════════════════════

【游戏概述】

控制一条小蛇在场地中觅食成长，避开围墙和系统小蛇。支持键盘
与鼠标双操控，可自定义难度、界面尺寸与系统小蛇智商。


【快速开始】

1. 主菜单选择"开始" → "开始"进入游戏。
2. 开场倒计时 3-2-1-GO 后游戏开始。
3. 控制小蛇吃掉食物"#"，每吃一个长度 +1，得分 +1。
4. 蛇头撞墙、撞自己身体（若开启）或撞到系统小蛇身体时，游戏
   结束。占满场地也可获胜。


【键盘控制】

+--------------+-------------------------------+
| 键位         | 功能                          |
+--------------+-------------------------------+
| ↑ / W / 5    | 向上移动                      |
| ↓ / S / 8    | 向下移动                      |
| ← / A / 7    | 向左移动                      |
| → / D / 9    | 向右移动                      |
| J            | 跳跃（当前方向单次前进两格）  |
| F / Tab      | 飞行（当前方向持续前进两格）  |
| P            | 暂停 / 继续                   |
| R            | 手动刷新画面                  |
| Q / O        | 退出当前游戏（确认对话框）    |
+--------------+-------------------------------+

【鼠标控制】

游戏区域右侧显示虚拟摇杆按钮，点击即可执行对应操作：

  [红色 ↑]  [绿色 ↓]  [蓝色 ←]  [黄色 →]

下方还有暂停按钮（灰色 ▶暂停）和退出按钮（灰色 ←退出）。

鼠标点击区域要求终端高度分别大于 16、21、26 行时才会显示对应
按钮。


【游戏元素】

● 您的小蛇：头为"@"（深蓝），身为"*"（浅蓝）。
● 系统小蛇：头为"$"（深绿），身为"%"（浅绿）。
● 食物：橙色"#"，随机生成。
● 围墙：棕色"▒"，静态障碍，撞上即游戏结束。
● 右侧信息栏：显示已游玩时间、当前得分以及新记录提示。


【游戏规则详解】

① 游戏区域为矩形，四周边界为围墙，不可穿越。
② 小蛇不能 180° 掉头（即不能直接反向移动），只能左右转。
③ 每吃一个食物，长度 +1，得分 +10。
④ 若开启"死亡条件"中的"自己蛇身"，则蛇头碰到自己身体也会结
  束游戏。
⑤ 系统小蛇若吃到食物会变长；若撞到围墙或您的小蛇则死亡，身
  体也全部变为食物。此时您可以吃掉它的身体，每吃一节长度+1，
  得分 +10。
⑥ 当您的蛇占满场地时，游戏自动胜利。
⑦ 若开启系统小蛇，且系统小蛇先占满场地，则系统小蛇获胜。


【设置菜单说明】

主菜单 → "设置" 下包含：

• 死亡条件：选择"A: 墙 / 其他小蛇"或"B: 墙 / 其他小蛇 / 自己
  蛇身"。
• 系统小蛇：开启或关闭 AI 小蛇。
• 更多设置：
    - 食物数量（1 ~ 20，默认 1）
    - 围墙数量（0 ~ 15，默认 0）
    - 界面宽（最小终端宽 ~ 终端宽 - 摇杆栏宽）
    - 界面高（最小终端高 ~ 终端高）
    - 移动速度（0.2s ~ 2.0s，默认 0.45s）
    - 系统小蛇智商（1 ~ 5，默认 3）
• 一键初始化：恢复全部默认值。

系统小蛇智商说明：
  1：无脑向最近食物移动，不避障
  2：向最近食物移动，优先方向被堵时随机选安全方向
  3：BFS 最短路径寻路（不忽略蛇尾）
  4：BFS + Flood Fill 空间评估（不忽略蛇尾）
  5：BFS（忽略蛇尾）+ Flood Fill，完整策略


【进阶技巧】

· 利用"跳跃"（J）和"飞行"（F/Tab）穿越狭窄通道或快速脱离包围。
· 引诱系统小蛇撞墙或撞您，可将其身体变为食物轻松获取。
· 若终端屏幕过小，游戏会自动提示。可按 Q 退出应用，或按 q
  退回主菜单进入"设置 → 更多设置"调整界面尺寸。
· 按 R 可手动刷新画面，解决显示异常。

【文件与配置】

游戏遵循 XDG Base Directory 规范存储配置：
  $XDG_CONFIG_HOME/gsb/  或  ~/.config/gsb/

配置文件：
  game.ini      游戏设置
  error.log     错误日志
  .error.sign   异常退出标记
  .lock.pid     单实例锁文件
